📊 Student Result Analysis

A Streamlit-based web application for analyzing and visualizing student academic results using Python, Pandas, Matplotlib, and Plotly.

📌 About the Project

**Student Result Analysis** is an interactive data analysis application that allows users to explore student marks and performance through tables, charts, and search functionality.

The application reads student result data from a CSV file and provides different views such as raw data, student performance summaries, top-performing students, and individual student results.

The project was developed to practice **Python data analysis, data visualization, and Streamlit application development**.

✨ Features

📋 View raw student data
📈 Analyze total and average marks of students
📊 Visualize student performance using charts
🏆 Find top-performing students
🔢 Select the number of toppers to display
🔍 Search for a student by name
📚 View a student's marks by subject
📊 Generate subject-wise marks visualizations
🖥️ Interactive sidebar navigation



🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| Python | Application development |
| Streamlit | Web application and user interface |
| Pandas | Data processing and analysis |

| Plotly | Interactive charts |
